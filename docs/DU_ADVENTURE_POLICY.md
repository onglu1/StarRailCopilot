# 冒险路线处理

本版本避开所有冒险关卡；进入后正常退出、结算、重开。

- 下一站选择及区域卡选择：有其他候选时排除冒险，再应用原优先级。刷新失败或用尽后的兜底也遵守此规则；只有冒险可选时进入后按冒险关直接退出。
- 关卡标题或说明页确认是冒险：持久化 `stop_requested` 与 `exit_reason=skip_adventure:…`，走原生退出菜单、确认和结算流程。无需识别具体挑战，也不寻找启动点或尝试完成挑战。
- 退出被战斗打断或控制器重启：保留退出请求，继续真实结算，不再次暂离恢复该房间。
- 只有观察到游戏结算页后才能结束记录；结果记 `interrupted`，保留原 run ID、关卡、历史及退出原因，然后按运行次数设置开始下一局。主动跳过仍进入整局失败率统计，不能当作通关或从分母中移除。
- 所有冒险均退出，包括射线、扑满及未知子类型；无秘技要求继续有效。

验证覆盖冒险路线筛除、未知冒险类型退出分派、真实结果前禁止结束，以及`interrupted`历史和下一局生命周期。局部页面回放只证明控制流程，不冒充实机结算；完整实机范围见[上线验收](DU_UNATTENDED_RELEASE.md)。
