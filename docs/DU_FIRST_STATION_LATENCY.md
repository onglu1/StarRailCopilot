## 统计口径

使用相邻两次真实结算完成时间之差，包括重新进入、加载、初始选择、战斗或秘技清怪、领奖、退出确认和返回入口。另记录本局 `started → finished` 作为辅助指标；验收使用更完整的结算间周期。

仅统计部署后开始、且观察到真实结算的首站局。部署时已经进行到一半的局不作为完整样本。每条采样记录均核实 `settlement_confirmed`、`settlement_observed`、`node_done` 为真；没有伪造结算、清空历史或把整局通关当成首站刷取。

战斗慢局全部计入，未只挑秘技秒杀局。本次采样范围没有未观察到结算或其他结果的记录被排除。用户的模式、难度、队伍、图鉴偏好和运行次数与优化前相同。p50达标不表示每局都在90秒以内，也不是对所有随机事件和系统负载的上限承诺。

## 本次改动

- 已识别的入口页面直接处理，减少无关弹窗扫描；用小范围识别右下、居中、续局三种启动按钮。
- 模式标题与按钮共同确认；标题暂未出现时继续检测，只有明确选错模式才返回。重新回到模式列表时重新准备入口。
- 复用调用方已获取的第一张选项画面，仍需要另一张真实截图确认稳定；晚出现的未收录标记会继续等待。
- 保留待结算进度的恢复流程给正常转场留出检测窗口，避免约18秒的正常载入被8秒未知页判断打断。
- 修正 OCR 内部固定960×960补边，让已裁剪的小区域真正以小尺寸进入检测模型；保留模型、缩放比例、坐标变换和阈值。
- CUDA识字输入仅补空白到模型原有宽度320，字符像素不变，保留单张批次和CPU回退。

移动、镜头、交互、战斗、月卡处理继续使用 SRC 原生实现，未增加固定等待或手工操纵模拟器。
