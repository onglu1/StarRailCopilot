# 货币战争与自动深渊整合版

本分支合并了 `abyss` 分支的最新工具实现和 Android 货币战争模块，框架与原货币战争目录使用同一上游版本。

## 启动

Windows 双击仓库根目录 `start.bat`，打开 `http://127.0.0.1:22369/`。它直接启动 SRC WebUI，不执行安装、代码自动更新或测试。

启动器依次使用 `SRC_PYTHON` 指定的 Python、`toolkit/python.exe`、`runtime/python.exe`、`.venv/Scripts/python.exe`，最后尝试 PATH 中的 Python。需要已有的 SRC Python 3.10+ 依赖环境；源码仓库不包含 Python 二进制。可以复用已有 SRC 环境：

PowerShell:

```powershell
$env:SRC_PYTHON = 'D:/path/to/existing/SRC/toolkit/python.exe'
./start.bat
```

通过 `SRC_WEBUI_PORT` 可更换端口。已有一体包若使用自身更新器，请将更新仓库和分支指向本 fork 的相应分支，避免更新后切回上游版本。

## WebUI 入口

| 功能 | 入口 | 运行方式 |
| --- | --- | --- |
| 货币战争 | 每周 → 货币战争 | 启用后从总览启动调度器；运行次数0为持续运行 |
| 虚构叙事 | 工具 → 虚构叙事 | 在工具页选择设置并启动，完成后停止 |
| 混沌回忆 | 工具 → 混沌回忆 | 在工具页选择设置并启动，完成后停止 |
| 末日幻影 | 工具 → 末日幻影 | 在工具页选择设置并启动，完成后停止 |

每个模拟器同时运行一个控制任务。持续货币战争会占用该配置，运行深渊前先停止它；不同模拟器使用不同配置。先在游戏内保存深渊要使用的两套预设编队，再设置预设编号。深渊保留 `abyss` 分支的最高层、攻坚、指定层策略，1–12预设、失败换序和分节点增益设置。

## 货币战争

- 支持正常对局和中途接管、标准/超频模式；没有刷开局流程。
- 攻略来源互斥：随机系统攻略、指定攻略码、随机码池、顺序攻略列表、三份预置攻略及自定义 JSON。原生码支持完整分享文本、`##...##` 或裸码。
- 顺序攻略每完整结算一局才推进一次，胜负都算；到列表末尾循环。暂停和重启保留当前项，每个配置独立计数。
- 速刷在指定关卡、掉血、首领或备战席拥挤时详细检查，其余关卡收掉落并检查免费商店。检查点可填 `1-3,2-1,2-3,3-1`。精刷每关完整管理。
- 每局固定一至两张三星核心，其余二星；整队选择优先羁绊，随后费用和星级。前期允许临时角色补位，中后期按成型人口发展，保护未来需要的攻略卡并保留利息存款。
- “通关必需羁绊”填写奖励条件，例如 `4贝洛伯格`；难度另行选择。日志中的基础羁绊估算不是游戏奖励已达成证明，星徽及特殊投资加成尚未完全核验。
- 优先选择带未收集标记的天赋等；明确奖励需要的星徽优先。月卡弹窗使用 SRC 原生处理。
- 商店锁定时先进入待处理节点，再按战斗、补给或事件页面继续。补给兼容四/五张候选卡。异常默认重启游戏接管3次，同关仍失败才停，手动停止不触发恢复。

## 本地数据与适配范围

账号配置保存在 `config/*.json`，货币战争记录、角色缓存和原生攻略保存在本仓库的 `state/currency_wars/`，可选截图保存在 `log/currency_wars/`。它们不会进入 Git。仓库模板为通用默认配置，需要自行填写模拟器连接；用户现有配置和运行记录不随代码公开上传。

当前游戏识别适配简体中文 Android、1280×720。深渊保留原实现限制：末日幻影三节点星启模式会跳过；混沌回忆主要扫描当前可见关卡。整合检查覆盖配置生成、任务导入和 WebUI 入口，不代表重新完成三种深渊的实机通关验收。
