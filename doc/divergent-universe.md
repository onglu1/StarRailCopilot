# 差分宇宙

WebUI → 工具 → 差分宇宙。使用简体中文 Android 游戏、1280×720，移动、截图、OCR、自动战斗和月卡处理复用 SRC。先停止同一模拟器正在运行的其他任务，再启动此工具。

| 设置 | 用途 |
| --- | --- |
| 演算类型 | 常规或周期演算；未完成的局保留原类型，新设置用于下一局 |
| 基础难度策略 | 常规演算 I–V 可沿用当前、指定或选择最高可挑战难度；选择后核对实际标题与可用启动按钮 |
| 附加难度策略 | 控制游戏中的阈值协议：沿用当前、指定0–4或最高可挑战，0关闭。协议入口不存在时，指定非零值会明确停止，不静默降级 |
| 首站速刷 | 进入首个战斗站点，战斗与奖励选择结束后主动结束并结算，刷拟合值/等级。记录为速刷结算，不是通关胜利 |
| 整局推进 | 继续寻找随意门、选择下一站并处理战斗、选项和事件，直到结算 |
| 运行次数 | 0持续运行；正数按本次启动的实际结算次数停止。中途接管保留原对局模式和进度 |
| 下载队伍预设 | 角色下载栏为空时使用游戏内指定预设，支持1–12；先确认预设页面出现，再选队，核对角色已填入后继续 |
| 优先补齐图鉴 | 按未收录、系统推荐、奖励等级依次排序；周期限定面具按本周可选项确认 |
| 同分选项关键词 | 用 `>` 分隔；未收录、推荐和等级三项相同后才用关键词打破平局 |
| 站点优先级 | 默认 `战斗 > 精英 > 商店`。没出现目标时有限刷新，刷新弹窗会确认 |
| 进战前使用秘技 | 使用当前角色秘技，默认关闭 |
| 积分满后停止 | 新一局前读取游戏积分，满额则停止。刷等级时可关闭 |
| 完成后领取积分奖励 | 本次运行结束后领取可领取的积分奖励，并关闭奖励面板 |
| 故障自动恢复次数 | 默认3次，保存现场后重启游戏接管；0为出错即停。用户停止不自动重启 |

当前策略参考 StarRailAssistant 的现行差分宇宙实现，移植了周期演算、首站结算/整局推进、站点选择与随意门识别；没有使用 PC 键鼠模拟。Android 系统返回键会弹出退出游戏窗口，因此脚本使用游戏内返回/退出控件。角色下载复用深渊预设编队选择，图鉴识别同时复用 SRC 的未收录图标和差分宇宙自己的图标。

周期演算首领旁的“污染等级”是首领信息，可调的附加难度控件名为“阈值协议”；两者分别识别。X 星阶入口属于另一种页面，不纳入“最高 I–V”枚举。

页面推进使用截图检测和 SRC Timer 超时/重试节流，没有点击后固定 sleep。卡片稳定、确认按钮启用、下一组卡片出现、预设队伍下载完成均有各自判断；地图帧复用模板结果，选项只 OCR 标题，不读取整段说明。未知页面先沿 SRC 页面关系返回主界面，找不到返回控件才由原生登录恢复。

导航复用 SRC 的 `MapControl` 镜头手势、`RogueExit.screen2direction` 出口投影、`JoystickContact` 移动、原生攻击/交互和 `Combat.combat_execute` 战斗循环。差分只提供随意门、交互箭头、站点标题和专属选择/结算页面。当前差分界面没有经典模拟宇宙的小地图，因此没有把经典坐标路线套到不存在的小地图上。找不到出口时可按 Assistant 流程暂离并继续当前局，保留对局进度。

随意门识别兼容远处、正面和侧面。差分没有模拟宇宙的域名牌，适配层将门的落地点交给原生投影，返回方向直接用于摇杆。镜头沿用原生安全区域、距离系数和触控后端。短战斗或直接消灭敌人后直接出现奖励时，同样会进入下一站，不再反复尝试接敌。

战后先在当前视角连续识别门，确认多帧未找到后才转镜头；门眼睛被角色或雨伞遮挡时也尝试门框特征。移动期间继续截图，交互出现或界面切换时立即结束当前摇杆动作。

事件房间识别问号牌并复用原生对话气泡、事件选项和确认流程。高处的问号用牌面底边转换为原生投影，避免接近时横向走过头；带睡眠标记的门不会当作可用出口。一个异常房间有多个事件时，完成其中一个后仍会寻找剩余事件。重连沿用原对局，登录完成后重新计算入口检测超时。

数据保存在 `state/divergent_universe/<配置名>.json`，包含当前局和实际结算记录。可选选择/结算截图在 `log/divergent_universe/<配置名>/`。结算确认弹窗不计完成；需要实际结算并返回入口。个人数据不会随源码上传。

2026-10-07 安卓 MuMu 实机验证：两次首站速刷真实结算；一局保留进度的周期演算完成难度 V、13/13 站“探索成功”，返回入口并记录胜利。验证覆盖电脑重启后的接管、短战斗直接给奖励、远处/侧面随意门、商店与精英/首领站，以及未收录选项优先。没有验证所有随机事件、所有队伍或其他难度的胜率。

辅助参考：[ADU](https://github.com/Waverider02/ADU) 的新条目优先思路，以及 [StarRailOneDragon](https://github.com/OneDragon-Anything/StarRailOneDragon) 的卡片识别和确认重试方式；具体游戏流程以 [StarRailAssistant](https://github.com/Shasnow/StarRailAssistant) 和当前手机画面为准。
